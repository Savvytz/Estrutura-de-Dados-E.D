# ED.2026.2
Estudo dirigido sobre o repositório de exemplos das aulas de Estrutura de Dados (MAE014) em 2026.2

Repositório da disciplina "Estruturas de Dados" (UFRJ-IM-DMA 2026.2), ministrada pelo professor Milton R Ramirez, do Departamento de Matemática Aplicada do Instituto de Matemática da UFRJ, oferecida no **segundo semestre de 2026** às turmas dos cursos de Matemática Aplicada e Engenharia Matemática, com vagas também para discentes dos Bacharelado em Matemática, Ciências Atuariais, Estatística, BCMT e Básico da Engenharia, através da disciplina MAE014 - Tópicos em Ciência de Dados B (turma SIGA 16351). As aulas ocorrerão às terças e quintas, de 15h às 17h, na sala CT-Decania-A 204.

As estruturas de dados e seus algoritmos representam a codificação do conceito matemático de Tipo Abstrato de Dados (TAD), um dos fundamentos da Ciência da Computação. As estruturas de dados desempenham um papel central no desenvolvimento de programas e sistemas computacionais em todas as áreas de aplicação da computação. Seu objetivo principal é organizar o armazenamento de dados dentro da hierarquia de memórias do computador, permitindo realizar operações básicas de inserção, recuperação, atualização e deleção de dados dessas memórias de forma eficiente, bem como facilitar determinadas computações e operações com eles, permitindo, por fim, o tratamento e gerenciamento de bases de dados, das pequenas às volumosas.

Existem diversas "famílias" de estruturas de dados, cada uma com suas características particulares. Algumas são projetadas para otimizar o o armazenamento de bases de dados, enquanto outras priorizam uma determinada operação, ou cálculo, com os dados, como a recuperação eficiente de informações. Tudo isso sempre considerando as características de operação da memória física. Por isso, o estudo das estruturas de dados e seus algoritmos é um requisito indispensável para qualquer um que deseje participar do desenvolvimento de soluções computacionais, seja no projeto, na codificação, nos testes ou na manutenção de programas e sistemas computacionais.

Compreender as estruturas de dados e os algoritmos a elas associados é fundamental para a criação de soluções computacionais eficientes e robustas. Essa base de conhecimento capacita os profissionais a tomar decisões adequadas no momento de selecionar a estrutura de dados mais adequada para cada problema e implementar os algoritmos mais eficientes para manipulação e gerência dos dados. Ademais, o estudo de estruturas de dados proporciona uma compreensão mais profunda sobre a ciência da computação e suas aplicações práticas, permitindo que os profissionais enfrentem os desafios do desenvolvimento de software com conhecimento e habilidades sólidas.

Adotaremos a metodologia de aprendizado clássica, com ligeiras modificações, baseada nos seguintes livros texto: 
 1) **Estruturas de Dados e Seus Algoritmos**; Jayme L. Szwarcfiter e Lilian Markenzon; 3a Edição; Editora GEN-LTC; 2020
 2) **Algoritmos, Teoria e Prática**; T.H. Cormen, C. E. Leiserson, R. L. Rivest, C Stein; 4a edição; Editora GEN LTC; 2024
 3) **Estruturas de Dados e Algoritmos em C++**; Adam Drozdek; 4a Edição; Editora CENGAGE Learning; 2017
 4) **Data Structures and Algorithms in Python**; Michael T. Goodrich, Roberto Tamassia, Michel H. Goldwasser; ISBN13 978-1118290279; Editora Wile; 2013
